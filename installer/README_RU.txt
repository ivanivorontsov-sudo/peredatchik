ПЕРЕДАТЧИК 1.0 — фото и файлы между телефоном (Android) и компьютером (Windows 10/11)
=====================================================================================

1. Установка
   • ПК: запустите Peredatchik-Setup-1.0.0.exe (или распакуйте переносную версию и запустите Peredatchik.exe).
     Если Windows покажет «Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае» (файл без цифровой подписи).
     При первом запуске разрешите доступ в частных сетях (или «Настройки → Разрешить в брандмауэре»).
   • Телефон: установите Peredatchik.apk, разрешите уведомления.

2. Сопряжение (один раз)
   ПК: «Сопрячь телефон» — появится QR-код и 6-значный код.
   Телефон: «Сопрячь с ПК по QR-коду» (или «по 6-значному коду»).
   Наоборот тоже можно: на телефоне «Показать мой код», на ПК «Ввести код телефона».
   После сопряжения устройства узнают друг друга по ключам; посторонние подключиться не могут.

3. Телефон → ПК
   Галерея → выберите фото/скриншот (можно несколько) → «Поделиться» → «Передатчик: на ПК» → «Отправить».
   На ПК файлы появятся в «Изображения\Передатчик», всплывёт уведомление (щелчок открывает папку).

4. ПК → телефон
   • Проводник: правой кнопкой по файлу → «Отправить на телефон» (в Windows 11 — «Показать дополнительные параметры»),
     или «Открыть с помощью → Передатчик», или «Отправить → Телефон (Передатчик)».
   • Или перетащите файлы в окно «Передатчика».
   На телефоне: фото — Галерея, альбом «Передатчик» (Pictures/Передатчик), видео — Movies/Передатчик,
   остальное — Загрузки/Передатчик. Приходит уведомление.

5. Способы связи (выбор в настройках и при каждой отправке; «Авто» перебирает сам)
   • Wi-Fi — ПК и телефон в одной сети (устройства находят друг друга сами).
   • Точка доступа телефона — включите на телефоне точку доступа и подключите к ней ПК. Дальше как Wi-Fi.
   • USB-кабель без ADB — кабель + на телефоне «Настройки → Сеть → Точка доступа и модем → USB-модем». Дальше как Wi-Fi.
   • USB через ADB — нужен adb.exe (SDK Platform-Tools) и «Отладка по USB»; на ПК «Настройки → Настроить USB через ADB».
   • Bluetooth — сначала сопрягите телефон и ПК в настройках Bluetooth, затем в «Передатчике» укажите,
     какое Bluetooth-устройство соответствует компьютеру/телефону. Медленно, подходит для фото.
   • Через интернет — нужен свой сервер-ретранслятор: на любом VPS запустите
       peredatchik-host relay 47233
     и впишите «адрес:47233» в настройках обоих устройств. Ретранслятор видит только зашифрованные данные.
   • Вручную — IP:порт (по умолчанию порт 47232), например при пробросе портов на роутере.

6. Безопасность
   Ключи ECDH P-256, шифрование AES-256-GCM, закрепление ключей при сопряжении, проверка SHA-256 каждого файла.
   При обрыве передача докачивается с места остановки (до 3 попыток автоматически, или при повторной отправке).

Порты: UDP 47231 (поиск), TCP 47232 (передача), TCP 47233 (ретранслятор).
Данные программы: %APPDATA%\Peredatchik
